这是真实取数：每次诊断会实时调用扶摇接口。取不到的项会被如实标注为「未知」，不会补零或估算。

证据构成

这份诊断的两个坐标

认知事实 / 推断 / 未知 —— 由线型编码。事实由代码从接口字段算出；推断由模型生成，只能引用已有事实，引用不存在即整条丢弃；未知表示数据缺失、未披露或能力不可达。
倾向正面 / 负面 / 中性 / 矛盾 —— 由颜色编码，且每条都附判定规则，可点开查看。未知项没有倾向。

关于这份诊断

每条证据都可点开回看接口、参数、原始值、时点与口径。正面或负面不是观点，是规则判定，规则随证据一并展示。 未知项不做补零、不做估算。本产品不提供涨跌预测、收益承诺或买卖建议。

数据来源：同花顺金融数据服务（扶摇）。本页所有数字均可回溯至上述接口字段。
